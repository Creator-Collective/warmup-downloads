# creator collective warm-up downloads

public desktop beta downloads and setup guide. download the release for your computer, extract it, and open Creator Collective Browser. each person signs into their own instagram account.

**unsigned beta:** signed installers and testing on other computers are still pending. if your operating system blocks the app, report the message in an issue.

engagement shares and session limits are editable in session options. results depend on eligible content and available time. no account-safety or recommendation outcome is guaranteed.

this repository hosts only the download page and public release packages. no user profiles or credentials are included.
